shadow

CSS + optional JS

Five stacked shadows that read as physical depth. Lift on hover, or let the cursor act as the light source.

data-fx-light="cursor"

View Transitions

Name an element and it morphs between states, or between pages with transitions.css. lumafx.transition() wraps any DOM change and adds page presets.
