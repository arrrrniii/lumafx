form

runtime + server

One rule language for the browser and your server. Errors slide in under the field and update as you type, email typos get a one-tap fix, phone numbers settle into international format, passwords get a strength meter, and the server's answer lands on the right field. Try gmial.com, 069 123 4567, or taken@sphere.al.

Welcome! The server accepted it: same schema, same rules.

// rules.ts: written once
export const join = schema({
  name: 'required name',
  email: 'required email',
  phone: 'phone:AL',
  password: 'required password',
  confirm: 'required match:password',
  about: 'minlength:10 maxlength:160',
  terms: 'accepted',
});

// app/api/join/route.ts (Next.js)
export async function POST(req) {
  const r = join.validate(await req.formData(), { spam: true });
  if (!r.ok) return Response.json(r, { status: 422 });
  // r.data.phone === '+355691234567'
  return Response.json({ ok: true });
}

For builders

lumafx/editor

builder kit

Everything you need to put these effects inside your own page builder. Drag blocks from the left onto the page, drag them to reorder, then select one and pick an animation: hovering a preset previews it right on the block. Click a selected block again to animate a heading, text or image inside it. The panel is <fx-panel>, and every piece behind it is a function you can call from your own UI.

// Your builder stores effects as data…
block.fx = [{ effect: 'reveal', options: { from: 'zoom' } }, { effect: 'tilt' }];

// …and renders them as attributes, on the server or in the browser.
import { toAttributes, apply, sortable, place, catalog } from 'lumafx/editor';
toAttributes(block.fx); // { 'data-fx': 'reveal tilt', 'data-fx-from': 'zoom' }
apply(el, 'chars-flip');  // a preset id works too

// Drag and drop with springy reordering, and a palette that makes new blocks.
sortable(canvas, { group: 'page', onEnd: save });
sortable(palette, { group: 'page', clone: (tile) => makeBlock(tile.dataset.block) });

// Or drop in the ready panel.
panel.target = selectedBlock;
panel.addEventListener('fx-change', (e) => save(block.id, e.detail.fx));

Intelligent UI


    

      
lumafx/ui
AI · JSON

      
Your AI answers with blocks instead of walls of text: match cards, lineups on a pitch, live scores, standings, stats, charts, weather, places, tickets and seat maps, quizzes, follow-up questions and 30 more. The model writes JSON, and the blocks build themselves while it is still writing. The same JSON renders in your chat, in a blog post (server-rendered for SEO), and inside Claude or ChatGPT through MCP. Albanian and English, light and dark, and everything a model writes is escaped and checked.

Sample data except the Albania lineup, which is the published one. Click a follow-up question, pick a ticket or a stand: in a real chat those go back to the model.


// 1. Give the model the blocks: a tool definition (or prompt() for a system prompt).
import { anthropicTool, openaiTool, validate } from 'lumafx/ui/server';
tools: [anthropicTool()]  // render_ui({ blocks: [...] })

// 2. Render while it streams, in your chat.
import { stream } from 'lumafx/ui';
const s = stream(el, { lang: 'sq', timeZone: 'Europe/Tirane' });
on('input_json_delta', (d) => s.write(d.partial_json));
on('stop', () => s.end());
el.addEventListener('fxui:ask', (e) => send(e.detail.text));  // follow-up chips

// 3. Live scores: blocks with { live: { adapter, id } } update themselves.
lumafx.ui.adapter.set('scores', { subscribe: (id, block, push) => feed.watch(id, push) });

In Claude and ChatGPT
MCP Apps

      
lumafx-mcp is a small MCP server with one tool, render_ui. Hosts that support MCP Apps show the blocks inline and stream them in while the model writes; follow-up chips become the next message, links open through the host, and ticket picks reach the model. Hosts without UI get a clean text version. Add the tool to your own MCP server, or point your own tools at the same view.

      

        

          
Run it


// claude_desktop_config.json
{ "mcpServers": { "lumafx": {
  "command": "npx",
  "args": ["-y", "lumafx-mcp", "--stdio"]
} } }

# or over HTTP
npx lumafx-mcp --port 3001  # /mcp

        

        

          
Add it to your server


import { registerUI, uiToolMeta, uiResult }
  from 'lumafx-mcp';

registerUI(server);  // adds render_ui

server.registerTool('get_event',
  { inputSchema, _meta: uiToolMeta },
  async ({ slug }) =>
    uiResult(toBlocks(await getEvent(slug))));
